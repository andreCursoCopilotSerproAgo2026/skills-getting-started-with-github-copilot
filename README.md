## Testes

Para executar os testes locais e gerar relatório de cobertura:

1. Instale as dependências:

```bash
pip install -r requirements.txt
```

2. Rode a suíte de testes:

```bash
pytest -q
```

3. Rode os testes com cobertura:

```bash
pytest --cov=src --cov-report=term-missing
```

Se o comando `--cov` não for reconhecido, certifique-se de que `pytest-cov` está instalado no mesmo ambiente Python.
